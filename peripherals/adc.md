# ADC (Analog to Digital Converter)

Converts continuous analog voltage to discrete digital number.

## Key Metrics
- **Resolution**: Number of bits (e.g., 12-bit = 4096 steps).
- **Sampling Rate**: Samples per second (e.g., 1 MSPS).
- **Reference Voltage (Vref)**: Defines voltage range. Step size = Vref / (2^n - 1).
