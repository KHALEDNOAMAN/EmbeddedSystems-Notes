# Embedded Systems Notes
Welcome to my embedded systems study guide. This repository contains notes, examples, and diagrams covering various aspects of embedded systems development.

## Sections
- **ARM**: Architecture, memory map, boot process
- **Protocols**: I2C, SPI, UART, CAN, USB
- **RTOS**: Tasks, FreeRTOS, Synchronization
- **Peripherals**: GPIO, ADC, Timers, DMA
- **Debugging**: JTAG, GDB, Logic Analyzers
- **Memory**: Flash, RAM, Linker scripts
- **Power**: Low power modes, battery
- **Cheatsheets**: C programming, bit manipulation
